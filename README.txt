DREAM ROOM 소개 사이트

구성 파일
- index.html : 반응형 소개 웹사이트 본문
- robots.txt : 검색엔진 크롤러 허용 설정

GitHub Pages 무료 배포 방법
1. GitHub에 로그인하고 새 Public 저장소를 만듭니다.
2. 저장소 루트(root)에 index.html과 robots.txt를 업로드합니다.
3. Settings > Pages에서 Build and deployment를 Deploy from a branch로 선택합니다.
4. Branch는 main, 폴더는 /(root)로 선택하고 Save를 누릅니다.
5. 게시 완료 후 표시되는 https://사용자이름.github.io/저장소이름/ 주소를 열어 확인합니다.
6. 게시된 최종 주소를 Google Search Console에 URL 접두어 속성으로 등록하고 소유권 확인 및 URL 색인 생성 요청을 진행합니다.
